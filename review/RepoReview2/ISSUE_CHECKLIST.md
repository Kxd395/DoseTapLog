# Issue Checklist

- Missing ScrollView or safeAreaInset for action dock
- Buttons not disabled when state requires it
- Early or late override flows not reachable
- Live Activity not starting or ending
- Safety banner not showing violations
- Settings missing keys or not persisted
- WHOOP proxy missing API key check or rate limit
- SQL triggers missing or not enforced
- CSV export missing fields or bad timezone handling
- HealthKit permissions not surfaced in UI
- Undo not bounded by time or removes wrong event
- No Reset Night or leaves stale state
