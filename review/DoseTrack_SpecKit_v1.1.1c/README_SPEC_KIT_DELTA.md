## Spec Kit

This repository includes Spec Kit artifacts that serve as the single source of truth for requirements and architecture.

- Constitution: .specify/memory/constitution.md
- Current spec: .specify/memory/spec.md
- Technical plan: .specify/memory/plan.md
- Tasks: .specify/memory/tasks.md
- Snapshots: docs/specs/
- Architecture decisions: docs/architecture/

Update spec files in the same PR as behavior changes. Create a new snapshot under docs/specs for each significant feature set.
