# ⚠️ IMPORTANT: /speckit.analyze is a CHAT COMMAND

## You CANNOT run this in the terminal!

The command `/speckit.analyze` is a **GitHub Copilot Chat slash command**.

It does NOT work in:
- ❌ Terminal/zsh
- ❌ Bash scripts
- ❌ npm scripts
- ❌ Command line

It ONLY works in:
- ✅ **GitHub Copilot Chat Panel** (the chat interface in VS Code)

---

## How to Access the Chat Panel

### Option 1: Keyboard Shortcut
Press: `Cmd+Shift+I` (on Mac) or `Ctrl+Shift+I` (on Windows/Linux)

### Option 2: Click the Icon
Look for the chat icon in the VS Code sidebar (usually on the left side)

### Option 3: Menu
Go to: **View → Copilot Chat**
