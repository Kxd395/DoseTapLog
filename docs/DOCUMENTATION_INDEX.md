## Feature Documentation Map

### Dose 2 Gating System ⭐ NEW

**Documents:**
1. **`docs/design/DOSE2_LOGIC_FLOW.md`** - Complete logic with ASCII diagrams
2. **`docs/ops/DOSE2_GATING_COMPLETE.md`** - Implementation summary
3. **`docs/ops/TESTING_GUIDE_COMPLETE.md`** - Test procedures (includes Dose 2 tests)

**Implementation Files:**
- `DoseTrackIOS/DoseTrackIOS/Dose2Gate.swift`
- `DoseTrackIOS/DoseTrackIOS/Dose2Button.swift`
- `DoseTrackIOS/DoseTrackIOS/NightPlanExtensions.swift`

**Key Features:**
- 6-state state machine (needDose1, waiting, early, open, grace, missed)
- Confirmation dialogs for early/late overrides
- Override tracking in database
- TimelineView auto-refresh (30s)
- Safety guardrails (1.5-4.5g per dose, 3.0-9.0g nightly)

### Night Flow Integration

**Documents:**
1. **`docs/ops/NIGHT_FLOW_INTEGRATION_COMPLETE.md`** - Complete integration summary

- `DoseTrackIOS/DoseTrackIOS/NightFlowServices.swift`
- `DoseTrackIOS/DoseTrackIOS/DoseWindowActivity.swift`

**Key Components:**
- CountdownRingView (progress indicator)
- SafetyBanner (dose validation)
- DoseWindowService (timing calculations)
- NudgeScheduler (notifications)

### EventLog System

## How to Use This Index

### Finding Feature Documentation

1. **Check Feature Documentation Map** (above)
2. **Follow Document Relationships** (see flow diagrams)
3. **Use Quick Navigation** (top of page)

### Adding New Documentation

**When creating new docs:**

1. **Determine category:**
   - Product → `docs/`
   - Design → `docs/design/`
   - Operational → `docs/ops/`
   - Review → `docs/review-notes/`

2. **Add breadcrumbs at top:**
   ```markdown
   **📍 Location:** `docs/ops/YOUR_DOC.md`  
   **📚 Breadcrumbs:** `docs/` → `ops/` → **`YOUR_DOC.md`**
   ```

3. **Link related docs:**
   ```markdown
   **🔗 Related Documentation:**
   - Implementation: `path/to/related.md`
   - Testing: `path/to/tests.md`
   ```

4. **Update this index:**
   - Add to appropriate catalog table
   - Add to feature map (if applicable)
   - Update navigation diagram
